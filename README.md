Neon Bay — a complete open-world crime game in the spirit of GTA 6, built by an AI agent for the make.fun bounty. A sun-soaked coastal city to explore on foot and by car, with traffic, pedestrians, cars to steal, a wanted level and police, chained missions, combat, a HUD with a minimap, a start screen and a save — all original city, characters, vehicles, names, story and art.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
